Features

Everything you need to ship code faster, without giving up control.

Terminal + Web sync

Seamless real-time sync between the terminal TUI and the web dashboard. Start a session in one, resume in the other.

Bring your own key

Connect to OpenAI, Anthropic, Azure, Groq, Ollama, LM Studio, or any OpenAI-compatible endpoint. Your key stays on your machine.

Autonomous swarms

Deploy 5 specialized agents — coordinator, architect, coder, reviewer, tester — that work in parallel and merge results via git.

Prompt-to-binary

Describe a feature. OmniCode plans, codes, tests, cross-compiles, packages, signs, and creates a GitHub release with changelog.

Legacy code analysis

Archeologist mode scans your codebase for dead code, vulnerabilities, and bottlenecks. Generates architecture diagrams and migration plans.

Self-healing tests

When tests fail, OmniCode analyzes the output, generates a fix, applies it, and re-runs — up to 5 iterations per failure.

Supported providers

Connect to any LLM. Use cloud APIs or run models locally.

OpenAI Anthropic Azure OpenAI Groq Together AI Ollama LM Studio OpenAI-compatible

Works fully offline with local models. No internet required after initial setup.

Capabilities

15 agent types built into a single binary.

OmniCode breaks down any task into a structured plan, executes each step using available tools, and adapts based on results. Up to 50 steps per task with self-correction.

Every agent action runs in an isolated sandbox — direct filesystem, git worktree, Docker container, or Firecracker micro-VM. Automatic rollback on failure.

Full editor experience across terminal (ratatui TUI), web (Monaco Editor), and VS Code extension with syntax highlighting, diff view, and real-time collaboration.

Polls your CI provider every 30 seconds. On failure, auto-fetches logs, parses errors, generates a fix, commits, and pushes. Optionally auto-merges when tests pass.

Installs a webhook on your repo. Reviews every changed file line-by-line for bugs, security issues, and style violations. Posts comments via GitHub API.

Full codebase indexing with tree-sitter AST parsing, symbol extraction, embedding generation, and semantic search. Builds a knowledge graph of your codebase.

Monitors dependencies against registries. Detects breaking changes via semver. Applies upgrades with migration instructions and creates a PR.

Monitors production logs and alert sources. Parses stack traces, correlates with recent commits, generates a hotfix PR, and optionally deploys to staging.
