Everything You Need

15 powerful capabilities built into one agent

OmniCode breaks down any task into a structured plan, executes each step using available tools (read/write files, run commands, search code, git operations), and adapts based on results. Iterates up to 50 steps per task with self-correction.

Every agent action runs in an isolated sandbox — Direct (with warning), Git Worktree (creates temporary branch), Docker container, or Firecracker micro-VM. Rollback on failure is automatic.

Full-featured editor experience across terminal (ratatui TUI), web (Monaco Editor), and VS Code extension with syntax highlighting, multi-cursor, diff view, and real-time collaboration.

Spawn 5+ specialized AI agents (coordinator, architect, coder, reviewer, tester) that work concurrently on different aspects of a task. Each agent can use a different provider/model. Results are merged via git.

Polls your CI provider (GitHub Actions, Jenkins, CircleCI) every 30s. On failure, automatically fetches logs, parses errors, generates a fix, commits, and pushes. Optionally auto-merges when tests pass.

Installs a webhook on your repo. When a PR is opened, OmniCode reviews every changed file line-by-line for bugs, security issues, performance problems, and style violations. Posts line-by-line comments via GitHub API.

Generates README, API docs, Mermaid architecture diagrams, and sequence diagrams directly from your codebase. Updates automatically as your code changes. Export to PDF.

When tests fail, OmniCode reads the failure output, examines the test source, generates a fix (either in the test or the source code), applies it, and re-runs. Iterates up to 5 times.

Full codebase indexing with tree-sitter AST parsing, symbol extraction, embedding generation, and semantic search via vector similarity. Builds a knowledge graph of functions, classes, modules, and their relationships.

Monitors Cargo.toml, package.json, and requirements.txt dependencies against crates.io and npm registries. Detects breaking changes via semver. In sandbox, applies upgrades with migration instructions, tests, and creates a PR.

Scans your entire codebase, builds ASTs, identifies dead code, security vulnerabilities, and performance bottlenecks. Generates a "Codebase Bible" Markdown document with architecture analysis and Mermaid diagrams. Can also migrate code between languages.

Monitors production logs and alert sources (Sentry, Datadog, custom log files) every 30s. On error, parses stack traces, correlates with recent commits, generates a hotfix PR, and optionally auto-deploys to staging.

Interactive step-by-step wizard that learns the developer's role, skill level, and goals. Generates a personalized learning path with specific tasks (read files, run tests, fix bugs). Guides the developer through their first real change.

Captures every architectural decision from chat sessions and PR discussions. Stores in a searchable SQLite database. Query past decisions with semantic search. Tag cloud visualization. Chain of reasoning preserved.

Describe a feature in natural language. OmniCode plans, codes, tests, cross-compiles, packages (.tar.gz, .zip, .deb, .rpm, .msi), signs, creates a GitHub release with changelog. Full CI/CD pipeline in one command.

Frequently Asked Questions

Everything you need to know

🔐 Is my API key safe?▼

Yes. Your key is encrypted with AES-256-GCM using a key derived from your machine's hardware ID + hostname. It's never sent anywhere. Not even to our servers (there aren't any).

📡 Does OmniCode phone home?▼

Never. Zero telemetry. Zero data collection. OmniCode has no servers, no accounts, no analytics. The only network calls are to your configured LLM provider and optionally to GitHub for PR/code review features.

🌐 Can I use it offline?▼

Absolutely. Connect to Ollama or LM Studio running locally. No internet required. All features work offline except marketplace and remote provider access.

🦀 Which languages are supported?▼

All languages the LLM supports. The codebase indexer has first-class support for Rust, TypeScript, JavaScript, Python, Go, Java, C/C++, Ruby, and more via tree-sitter. The Cortex engine auto-detects language by file extension.

📦 Can I migrate a legacy codebase?▼

Yes. The Archeologist mode analyzes your entire codebase for dead code, vulnerabilities, and bottlenecks. It can also migrate code between languages (e.g., Python → Rust, JavaScript → TypeScript) in a sandboxed environment with equivalence testing.

🚨 What happens when production breaks?▼

Incident Whisperer monitors your logs and alert sources. It parses stack traces, correlates with recent commits, generates a hotfix, creates a PR, and optionally deploys to staging. You approve before production deployment.

🧪 Can it fix my failing tests?▼

Yes. The self-healing mode runs your tests, parses failures, analyzes the source, generates fixes, and re-runs. It iterates up to 5 times per failure and can fix both test code and source code.

🤝 How does collaboration work?▼

Create a session (generates an 8-char code), share it with your team. They join via `omni join `. Real-time file sync, multi-cursor, chat. Under the hood it uses WebSocket + CRDT-like conflict resolution.

🔧 Can I create custom skills?▼

Yes. Skills are self-contained packages with a manifest.json, hooks, and prompts. Publish to the marketplace or keep them private. Install with `omni skill install `.

🔒 Is there an audit trail?▼

Yes. Compliance mode enables a signed, hash-chained ledger of every action taken by OmniCode. Each entry is cryptographically signed and linked to the previous entry. Export as JSON or CSV for audit.

🐳 Can I run it in Docker?▼

Yes. Deploy as a container, access the web UI from any device. OmniCode also uses Docker for sandboxed agent execution (isolates file system and network). Supports Firecracker micro-VMs for maximum isolation.

🆓 Is it really free?▼

Yes. The Community edition is fully free and open source (MIT license). No feature limits, no usage caps. Enterprise edition adds SSO, audit exports, priority support, and custom SLAs for teams.
