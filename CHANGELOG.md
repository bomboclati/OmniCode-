# Changelog

- Initial release
- CLI with 21+ subcommands (agent, server, tui, review, heal, deploy, etc.)
- Multi-agent orchestration (sentinel, review, heal, release, guardian, historian, swarm)
- LLM orchestration engine with streaming and multi-provider support
- Real-time collaboration via WebSocket server
- Sandboxed code execution (containers for unsafe ops)
- Cloud deployment to AWS/GCP/Azure/DigitalOcean
- Project archeology, incident management, onboarding flow
- Web UI with agent dashboard, file viewer, graph viewer, settings
- VS Code extension with sidebar panel + status bar integration
- Windows package manager (winget) support
- Single-file landing page at omnicode.ai
